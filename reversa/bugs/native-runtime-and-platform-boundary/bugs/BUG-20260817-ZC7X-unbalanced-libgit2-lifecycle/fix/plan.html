Defect and root cause

The package calls reference-counted git_libgit2_init() at 66 public entry points and has no git_libgit2_shutdown() path. No isolate, wrapper, call, or application boundary owns the increments, and initialization failures are ignored.

confirmed causedeterministic 1/1native count 2 → 3 → 4present since d34661a

Fresh runtime evidence proves that two Libgit2.version calls each grow the native counter. Evidence: reproduction capsule, confirmed root cause, and static analysis.

Chosen strategy

Multi-agent debate winner: Candidate A, with selected safeguards from Candidates B and C. Introduce one checked native lease per Dart isolate, transient logical pins for otherwise ownerless native calls, persistent one-shot owner tokens for independently usable wrappers, and an explicit guarded terminal Libgit2.shutdown().

The strategy was selected because it removes unbounded increments while preventing shutdown during an active call or live native ownership. Cleanup releases its pin only after confirmed destruction or valid transfer; successful shutdown is idempotent and terminal for the isolate so platform/global configuration is never silently lost through transparent reinitialization.

Judge record: debate/resposta-final.md.

Risk and Agent Notes

  • Change risk is high: process-global native state is coordinated by isolate-local Dart bookkeeping across 66 entry points.
  • The dominant risk is an incomplete ownership inventory. Missing one independently usable owner permits premature shutdown; pinning a borrowed view can block shutdown indefinitely.
  • Dart finalizers are nondeterministic. Deterministic users must explicitly release wrappers before calling shutdown; finalizers never trigger automatic shutdown.
  • Cleanup failure retains the logical pin and may leave a bounded lease. This fail-closed result is safer than certifying shutdown while native ownership is uncertain.
  • Successful shutdown is terminal for the isolate. Multiple runtime epochs and replay of Android CA or process-global options are intentionally out of scope.
  • Global option concurrency across isolates, abrupt isolate termination, and the related extensions-array leak remain separate limitations.
  • No generated FFI declaration, git2dart_binaries artifact, ABI, migration, historical data repair, or dependency change is planned.
  • Cross-platform CI, merge, tag, release, and publication require separate evidence or authorization; package closure may remain unsatisfied.
