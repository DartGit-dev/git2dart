# Later Depth Inspection Occurrences

- History and integration: merge, reset, revert, and cherry-pick options are used after unchecked initializer calls.
- Git objects and ODB: blob filter options use the same unchecked pattern.
- Repository lifecycle: repository init, clone, status, and worktree options add further occurrences.

These are the same ABI and error-contract mechanism tracked by BUG-20260817-QWMA.
