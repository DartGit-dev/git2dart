Defect and confirmed cause

The recorded getter converted a libgit2-owned string array and released only the Dart outer allocation. The current getter now disposes the native array in finally before freeing the outer allocation, matching the confirmed native-memory rule.

Chosen strategy

Direct disposal audit. Verify conversion occurs before disposal, the disposer is in a finally path, and local extension getter/setter behavior remains intact. No network, public API, ABI, or persistent data change is in scope.
