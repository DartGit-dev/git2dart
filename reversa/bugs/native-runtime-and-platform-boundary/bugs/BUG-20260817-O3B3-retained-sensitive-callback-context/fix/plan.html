Defect and confirmed root cause

Operation-scoped callback state has no single lexical cleanup owner. A controlled local failure reproduced retained state in 3/3 isolated runs. Details remain inside this restricted bug folder.

Evidence: reproduction capsule, root cause, and isolated judge recommendation.

Selected strategy

Multi-agent debate winner: Proposal C with coverage from A and B. Add one internal synchronous RemoteCallbacks.withCallbackState<T>. Its try begins before state installation; its finally performs only the existing pure-Dart reset. Each native call and immediate error translation remains inside the protected closure.

All three solvers converged on this mechanism. The judge selected its repeated-failure and special-family validation while excluding payload ownership and concurrency.
