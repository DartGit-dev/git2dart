Defect and confirmed root cause

Credential callback memory has no single lifecycle owner. Callback setup allocates a native attempt payload that reset does not release, while the SSH-key builder independently bypasses the established arena for one output slot and four temporary strings.

Evidence: 3/3 reproduction, root-cause trace, and automated bisect. Bisect identified 37c3c41d3073207ccd2cf362acf39b05e719a5ae as the first bad commit.

Selected strategy — authorized

Direct correction authorized on 2026-08-21. Restore arena ownership for call-scoped SSH-key inputs and give the credential callback payload one explicit, idempotent release path in RemoteCallbacks.reset(). The already-applied O3B3 lexical owner guarantees that reset runs after each migrated synchronous operation.

Supplemental gap found during verification. The bug record also covers two error-message buffers passed to git_error_set_str(). Libgit2 duplicates these strings, so their Dart FFI buffers must use a short arena scope instead of unmanaged toCharAlloc(). This supplemental change remains gated.
