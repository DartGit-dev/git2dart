BUG-007 · BUG-20260817-CIKD

Serialized remote callback bridge

High / P1. Process-static callback state is protected by a reentrancy guard until operation-local isolation is proven.

Confirmed cause and strategy

A later callback-bearing operation could overwrite process-static closures of an active operation. The chosen, existing strategy rejects overlap before callback installation and resets state in finally.

Risk and limits

Concurrency risk remains medium: the supported behavior is serialization, not concurrent isolation. Dynamic multi-thread, exception/cancellation, network, and platform-matrix evidence remains pending.

Specification and delivery

The existing interim serialization rule supports spec-correta. The correction is contained by local/origin 0.5.5; package publication is pending.
