Root commit creation writes through a zero-length parent array.

Defect and confirmed root cause

All three commit serializers allocate parentCount pointer elements. When the parent list is empty, parentCount is zero, but the empty branch still writes parentsC[0] = nullptr.

Epistemic state: CONFIRMED. The complete causal path is present in source and reproduced in 3/3 FFI serializers; both public root-commit routes are reachable.

  • Static analysis evidence
  • Reproduction capsule

Chosen strategy

Apply a direct, minimal correction. Empty parent lists pass a null pointer to libgit2. Non-empty lists allocate exactly the required number of pointer elements and copy the parents. This preserves public behavior and removes the invalid write.
