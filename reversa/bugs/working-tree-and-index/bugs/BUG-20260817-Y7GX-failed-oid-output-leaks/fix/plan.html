Fix plan · BUG-20260817-Y7GX

Working tree and index · 2026-08-27 · medium/P2 · low risk

Defect and confirmed cause

Five fallible OID-producing adapters allocated output before a native call and formerly propagated an error without release. Current inspection finds each success path returns its owner and each throwing path frees that output before rethrow.

Chosen strategy

Direct failure-ownership audit. Verify all five adapters have exact-once failure cleanup, exercise existing local success and failure regressions, and record delivery. No public API, ABI, network operation, or persistent data change is in scope.

Proof boundary

Focused local tests and analyzer establish success/error behavior and control-flow ownership. They do not include native heap instrumentation or all-platform coverage.

Specification

The likely evidence-based verdict is spec-correta: the effective ownership design and ADR-003 already require output buffers to be released before error propagation.
