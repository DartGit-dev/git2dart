Fix plan · BUG-20260817-8HNA

Working tree and index · 2026-08-27 · medium/P2 · low risk

Defect and confirmed cause

The recorded defect was a checkout-options helper allocating native temporaries outside the arena owned by stash apply and pop. Current inspection finds the helper receives that arena and allocates its options and path array through it; the historical cause is confirmed by static analysis.

Chosen strategy

Direct ownership audit. Reuse the current caller-owned arena pattern, prove its source contract and local apply/pop behavior, then record delivery. No public API, ABI, persistent data, or network operation is in scope.

Current code already satisfies CHG-002 structurally; no new source or test diff is proposed unless validation disproves that finding.

Planned proof

A focused local stash suite and focused analyzer will verify ownership without network access. Historical static proof distinguishes the former global allocations from the current arena path. The proof does not instrument native heap growth or every supported platform.

Specification and relationship

The likely evidence-based verdict is spec-correta: the memory ADR already requires one owner for temporary native allocations. BUG-20260817-8HNA is related to BUG-20260817-47ZS through temporary native ownership.
