Fix plan · #13 BUG-20260817-6KRT

working-tree-and-index · 2026-08-26 · severity: high · priority: P1

Defect and root cause

Three fallible native calls return integer statuses, but their binding adapters discard them. Consequently public Index.read, readTree, and write can report success on native failure.

Root-cause state: supported. Evidence: complete static enumeration; red failure-path tests will validate each status.

Chosen strategy

Direct correction. Route each already-returned native status through the existing shared checkErrorAndThrow boundary. No API, ownership, or persistence model changes are required.

Correction change set

CHGTypeArtifactPurpose
CHG-001testtest/index_test.dartProve all three native failure paths throw and valid behavior remains covered.
CHG-002codelib/src/bindings/index.dartTranslate every ignored index I/O status at the binding boundary.

Planned tests

Reproduction: invoke read and write on an in-memory index plus readTree with a null tree; current code returns normally.

Regression: the same operations throw LibGit2Error after the correction. Existing disk write/read and valid tree tests preserve successful behavior.

Risk and exclusions

Change risk: low. The diff checks three already-defined return codes with the repository's standard error translator. Valid native status zero remains a no-op.

No recovery of any historically missed write failure is possible or proposed; the patch prevents future false-success returns only.
