Borrowed TreeEntry values expose an invalid native free operation.

criticalP0
Context
git-objects-and-object-database

2026-08-20
Strategy
Direct correction

Defect and confirmed root cause

Index, filename, OID, and entries-list lookups return pointers owned by the parent tree. Path lookup returns a caller-owned duplicate. The high-level wrapper represents both ownership modes as TreeEntry without retaining ownership state, while TreeEntry.free() unconditionally calls git_tree_entry_free.

Epistemic state: CONFIRMED. Three of three isolated Flutter workers terminated with exit code 79 after a borrowed entry was manually released and native cleanup continued.

  • Static analysis evidence
  • Reproduction capsule
  • Isolated reproduction test

Chosen strategy

Apply a direct ownership guard in TreeEntry. Borrowed constructors record borrowed ownership; the path constructor records caller ownership. free() rejects borrowed entries with StateError before any native call, while owned path entries keep their current native release and finalizer detachment.

Planned tests

Reproduction proof

A negative ownership test calls free() on borrowed entries from all four high-level construction paths and requires a Dart StateError. Before CHG-002, the same operation enters the native destructor and the test worker fails.

Regression proof

  • The parent tree remains usable after each rejected borrowed release.
  • An owned path entry remains manually releasable.
  • The complete tree test file passes after the patch.
  • Formatter and analyzer remain clean.

Risk and boundaries

Change risk: medium. The change replaces native heap corruption with an explicit Dart failure for an invalid public call. It is localized and reversible, but four borrowed construction paths and one owned path must preserve distinct behavior.

Risk controls

  • Red-before-green proof for each high-level ownership route.
  • No change to the native binding contract or pointer allocation.
  • No data repair or dependency-version change.

Agent Notes — explicitly out of scope

  • No public type hierarchy split and no duplication of every borrowed entry.
  • No changes to libgit2, git2dart_binaries, or generated bindings.
  • Use of a borrowed entry after its parent tree is freed remains the separate documented lifetime gap.
  • Repeated manual release of an already-freed owned entry remains outside this correction.
  • No changes to T8MW or unrelated working-tree modifications.
  • No commit, push, package publication, or backport in this correction gate.
