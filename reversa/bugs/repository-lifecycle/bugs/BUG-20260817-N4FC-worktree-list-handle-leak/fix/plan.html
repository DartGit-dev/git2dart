#27 · BUG-20260817-N4FC

medium P2 Worktree list leaks every looked-up native worktree handle.

Defect and confirmed root cause

The binding returns owning git_worktree handles. Historically, public Worktree.list copied their names and discarded the handles, leaking one native allocation per listed worktree. Commit e2d8bb4 encloses name projection in try/finally and releases every handle in the finally loop, including exceptional mapping paths.

Evidence state: confirmed by historical diff, blame, and current-head source audit.

Chosen strategy

Direct, minimal audit. The complete ownership correction already exists in the current branch. No new product patch is proposed; validation covers listing, creation, pruning, and the native list error path.
