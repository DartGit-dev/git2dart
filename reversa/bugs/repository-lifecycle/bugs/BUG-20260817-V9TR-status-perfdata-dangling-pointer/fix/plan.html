Defect and root cause

listPerfdata allocates git_diff_perfdata in an FFI Arena but leaves its required version field at zero. Libgit2 rejects the call before producing counters. Once initialized, the function still returns the allocation, and the installed FFI using implementation releases the Arena in finally before the caller receives it.

deterministic 1/1six-step bisectno current call sites

Evidence: reproduction capsule and static analysis. The isolated bisect identifies ca9e4a6810793028d245bc9a404f4d970e5ac8cd as the first bad commit.

Chosen strategy

Bisect-confirmed direct correction. Initialize the native structure version, then copy both counters into an immutable Dart value before the Arena is released. This matches the established DiffPerfData pattern and removes the raw pointer from the return contract.
