#26 · BUG-20260817-L8WX

medium P2 Repository identity lookup silently ignores native failures.

Defect and confirmed root cause

Historically, identity called git_repository_ident and read its output pointers without checking the native status. That turned a native repository failure into an empty or partial identity result. Historical diff 1914a905 records the corrective ordering: capture the status, call checkErrorAndThrow before reading pointers, and free both temporary output slots in finally.

Evidence state: confirmed by the historical diff and current-head source audit.

Chosen strategy

Direct, minimal audit. The necessary binding correction is already contained in the current branch, so no new product patch is proposed. Local validation confirms configured and absent-identity behavior; static source inspection confirms the native-error path is translated before any output dereference.

Planned proof

  • Regression: test/repository_empty_test.dart verifies a configured identity is returned and an unset identity produces the documented empty public value.
  • Error-path proof: static current-head review verifies checkErrorAndThrow(error) precedes both pointer conversions. No safe public test seam can force libgit2 to fail identity lookup without injecting a binding or passing an invalid native handle, so no unsafe test is added.
  • Quality: focused Flutter test, focused analyzer, historical diff integrity, and branch containment checks.

Risk and boundaries

Low — the historical change is local to one adapter and only restores the existing native-error contract. No public API, data migration, network access, or unrelated cleanup is in scope.
