Fix plan · #10 BUG-20260817-BVMB

references-and-remotes · 2026-08-26 · severity: high · priority: P1

Defect and root cause

git_remote_get_refspec returns a nullable pointer for an invalid position. The binding forwards it, and Remote.getRefspec creates a public wrapper that will dereference null later.

Root-cause state: supported. Evidence: static analysis and the affected binding. The red boundary tests will confirm the runtime path.

Chosen strategy

Direct correction. A neighboring index binding already validates null results with Git2DartError; using that established contract is the smallest compatible change.

Correction change set

CHG-001testtest/remote_test.dartProve valid boundary success and invalid lower/upper bounds fail at lookup.

Planned tests

Reproduction: request index refspecCount and show that current code returns a wrapper instead of throwing.

Regression: index zero remains usable; both -1 and refspecCount fail immediately with Git2DartError.

Risk and exclusions

Change risk: low. This adds a null guard at the Dart FFI boundary, without changing the public method signature, valid behavior, ownership, or native ABI.

No data repair is needed: invalid lookups do not persist or mutate repository data.
