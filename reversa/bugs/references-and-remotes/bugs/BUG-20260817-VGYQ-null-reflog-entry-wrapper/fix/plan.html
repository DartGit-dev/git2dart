Fix plan · #11 BUG-20260817-VGYQ

references-and-remotes · 2026-08-26 · severity: high · priority: P1

Defect and root cause

git_reflog_entry_byindex returns a nullable borrowed pointer. The binding forwards it, and the public index operator constructs a wrapper that dereferences null later.

Root-cause state: supported. Evidence: static analysis; runtime boundary tests will confirm the path.

Chosen strategy

Direct correction. It mirrors the established null-result handling pattern at this Dart FFI boundary without changing valid lookup behavior.

Correction change set

CHGTypeArtifactPurpose
CHG-001testtest/reflog_test.dartCover empty, valid first/last, and invalid lower/upper reflog indexes.
CHG-002codelib/src/bindings/reflog.dartTranslate null native entries into an immediate Dart error.

Planned tests

Reproduction: read index length and show current code returns a wrapper rather than throwing.

Regression: empty tag reflog has length zero, valid first and last entries remain available, and -1 plus length fail immediately with Git2DartError.

Risk and exclusions

Change risk: low. One null guard is added at the FFI boundary; public signature, valid borrowed-entry lifetime, ownership, and native ABI remain unchanged.

No data repair is needed because invalid reads do not mutate reflog data.
