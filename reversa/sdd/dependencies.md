## Native and System Dependencies

- `libgit2` binaries and generated declarations are delivered by `git2dart_binaries`; normal development in this repository does not regenerate them.
- Linux documentation calls out OpenSSL development libraries and PCRE 3 compatibility.
- macOS documentation calls out OpenSSL.
- Windows documentation calls out OpenSSL and requires the directory containing `libgit2.dll` on `PATH` for tests.
- Android and iOS execution is validated through Flutter device targets in CI.

## Tooling and Delivery Dependencies

- GitHub Actions uses `actions/checkout@v3`, `subosito/flutter-action@v2`, `reactivecircus/android-emulator-runner@v2`, and `k-paxian/dart-package-publisher@master`.
- The package manager is Dart pub, driven by `flutter pub get` and `pubspec.lock`.
- Publication targets pub.dev and is gated by the multi-platform test job.
- `tool/api_diff/` is an isolated Dart utility package used to compare public declarations between `git2dart_binaries` releases.
