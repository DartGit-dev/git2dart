## Executive Summary

- 🟢 **CONFIRMED**: `git2dart` is a null-safe Dart/Flutter package that exposes idiomatic Dart wrappers around libgit2.
- 🟢 **CONFIRMED**: Native libraries and generated FFI declarations come from the companion `git2dart_binaries` package; this repository owns the higher-level API and hand-written binding adapters.
- 🟢 **CONFIRMED**: The package targets Dart `>=3.7.2 <4.0.0`, Flutter `>=3.29.3`, and Android, iOS, Linux, macOS, and Windows.
- 🟢 **CONFIRMED**: The repository contains no application server, database schema, migrations, HTTP routing layer, Docker configuration, or environment template.

## Functional Modules

The source is primarily flat and type-oriented, so these modules are semantic feature groups rather than top-level source directories.

1. **Repository lifecycle** — initialization, discovery, opening, cloning, worktrees, and repository state.
2. **Git objects and object database** — blobs, commits, trees, tags, OIDs, ODB, commit graph, signatures, and blob streams.
3. **Working tree and index** — checkout, status, index, diff, patch, stash, ignore, attributes, filters, and pathspecs.
4. **References and remotes** — references, branches, reflogs, refspecs, remotes, callbacks, credentials, and certificates.
5. **History and integration operations** — revision parsing/walking, merge, rebase, reset, blame, notes, mailmap, pack building, and submodules.
6. **Native runtime and platform boundary** — libgit2 initialization, platform-specific loading, shared Git enums, errors, and `lib/src/bindings/`.
