---

## How the Reviewer creates this file

For each gap 🔴 that only the user can solve, create an entry:

```markdown
## Question [N]

**Context:** [Where in the system did this question arise — module, function, line]
**Spec afetada:** [`reversa/sdd/<unit>/{requirements|design|tasks}.md`]
**Question:** [Direct question, without ambiguity]
**Impact:** [What changes in the spec depending on the answer]

**Answer:** <!-- fill in here -->
```

---

## How the user responds

The user must:
1. Fill in the `**Resposta:**` field for each question
2. Notify the Reviewer when finished (type `reversa` or "I answered the questions")

---

## How the Reviewer processes responses

After receiving notice from the user:
1. Read the full file
2. For each question with a completed answer:
- Update the corresponding spec
- Reclassify the item according to the answer (🔴→🟢 or 🔴→🟡)
- Mark the question as `✅ Respondida` above the Answer field
3. For unanswered questions: leave as 🔴 in the final report
4. Update `confidence-report.md` with the new percentages
