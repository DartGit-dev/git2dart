# Selo Generativo

Creates **unique and reproducible visual badges** for Reversa projects using p5.js. Each project receives its own generative artwork derived from a deterministic seed: the same seed generates the same stamp, every time.

Inspired by the Art Blocks pattern (seeded randomness) and Anthropic's `algorithmic-art` skill, but with a deliberately smaller scope: it produces **just the seal**, not a philosophical manifesto, not an exploration platform. It is a decorative element of identity.

## When to use

- **Hero of `index.html`** from the mini-site generated by `/reversa-documentation`.
- **Mini-stamp in the header** of each page of the mini-site (shortened version).
- **Capa de slides** no `deck.html`.
- **Visual identity** of any artifact generated by Reversa that requires a distinctive mark.

The skill is **lightweight by design**: it uses only p5.js, generates a single canvas, exports as SVG or PNG. There is no exploration sidebar, there are no multiple modes, there is no mandatory animation (animation is optional).

## Principles

1. **Absolute reproducibility**: the same seed always generates the same seal.
2. **Limited palette**: 3 to 5 colors per badge, derived from the chosen visual style.
3. **Balanced composition**: recognizable central form with auxiliary elements orbiting or composing it.
4. **No text on the canvas**: the seal is purely visual; project name and title are outside the canvas, in HTML.
5. **Size adaptable**: the same canvas works in 64x64 (mini-header stamp) and 800x800 (large hero).
6. **No dependencies other than p5.js**: no GSAP, dat.GUI, lodash. Only p5.

## Fluxo de Trabalho

### 1. Receive the seed

O seed pode vir de:

- **Direct string**: user or agent passes a sha256 hash, project name, or any string.
- **File path**: user points to `.reversa/soul.md`, the skill computes `sha256` of the content.
- **Fallback**: if nothing is provided, use `sha256` of the current timestamp ("current" stamp, not reproducible).

```javascript
async function computeSeed(input) {
    const enc = new TextEncoder();
    const data = enc.encode(input);
    const hashBuffer = await crypto.subtle.digest("SHA-256", data);
    const hashArray = Array.from(new Uint8Array(hashBuffer));
    const hashHex = hashArray.map((b) => b.toString(16).padStart(2, "0")).join("");
    return hashHex;
}
```

The seed is a 64-character hexadecimal string. The skill extracts multiple numbers from it to feed different parameters.

### 2. Choose a palette

The palette derives from the visual style chosen by the `/reversa-documentation` user, or can be provided directly.

See `references/PALETTE_BY_STYLE.md` for the complete table of palettes by style. The 4 base palettes are:

| Style | Palette |
|--------|--------|
| `sober` | Neutral tones: grays, teal, light terracotta, broken white |
| `premium` | Dark mode: preto profundo, dourado, vermelho-vinho, prata, azul-meia-noite |
| `dense` | Saturated: orange, cyan, magenta, lime, indigo |
| `exploratory` | Luminous pastels: dawn pink, glacial cyan, mist lilac, light white |

The choice of which color is "central" and which are "auxiliary" comes from the seed.

### 3. Choose generative pattern

The skill has **5 established patterns**, each with a distinct appearance. The seed determines which pattern to use (first 2 hex modulo 5 digits):

| Standard | Appearance | When it matches |
|--------|-----------|----------------|
| `flow-field` | Perlin flow fields, curved organic traces | Style `sober`, `exploratory` |
| `particle-orbit` | Particles orbiting a center with tracks | Style `premium`, `exploratory` |
| `crystal-lattice` | Symmetrical crystalline shape, clean geometry | Style `dense`, `sober` |
| `wave-interference` | Moiré interference patterns, circular waves | Style `premium`, `dense` |
| `noise-strata` | Horizontal noise strata, abstract landscape | Style `sober`, `exploratory` |

Detalhes em `references/GENERATIVE_PATTERNS.md`.

The skill can accept override of the pattern via parameter, ignoring the seed derivation.

### 4. Generate the code

Estrutura do HTML resultante:

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">

<body>
    <div>
        <div id="seal-container"></div>
        <div class="label"><!-- PROJECT_NAME --></div>
    </div>
    <script id="seal-config" type="application/json">
        <!-- CONFIG_JSON -->
    </script>
    <script>
// 1. Read config (seed, palette, pattern, size)
        // 2. Seedar p5.js: randomSeed(seedInt); noiseSeed(seedInt);
// 3. Execute chosen pattern
// 4. Save canvas as reference
    </script>
</body>
</html>
```

**Fundamental rules**:

1. **Standalone HTML**: single file, p5.js via CDN, nothing external.
2. **p5.js 1.9.0+**: use `https://cdnjs.cloudflare.com/ajax/libs/p5.js/1.9.0/p5.min.js`.
3. **Always seeded**: `randomSeed(seedInt)` and `noiseSeed(seedInt)` in the first setup, before any call to `random()` or `noise()`.
4. **Conversion from hex hash to int**: take first 16 hex chars, convert via `parseInt(hex.slice(0, 16), 16)`.
5. **Square Canvas**: default size 800x800, but configurable.
6. **noLoop()**: by default the seal is static. If animation is requested, use `frameRate(30)` and low-cost algorithm.
7. **No text on the canvas**: project name is in `<div class="label">` outside the canvas.

### 5. Size variants

The skill accepts parameter `size` to generate large (hero, 800x800), medium (slide cover, 400x400) or mini (header, 64x64 or 128x128) stamp.

On smaller stamps (<200px), apply automatic simplifications:
- Reduce particle count by 80%.
- Increase stroke thickness proportionally.
- Disable animation.

## Quality guidelines

- **Recognizability**: the seal must have a strong central shape; Anyone who has seen it once must recognize the project by its seal.
- **Color balance**: never use all the colors in the palette on the same stamp; typically 1 dominant color (60%), 1 secondary (30%), 1 accent (10%).
- **Do not attract more attention than the content**: the seal is identity, not focus. In big hero, it's ok to be the protagonist; in a mini-stamp in the header, it must give space to the name of the project.
- **Accessibility**: minimum contrast between background and primary elements. Stamps with a dark background have light elements and vice versa.
- **Language**: comments in PT-BR, without indents.

## Code Guidelines

- **Constants named at the top**: size, palette, pattern parameters visible at the beginning.
- **Single generation function**: each pattern is a function `drawFlowField()`, `drawCrystalLattice()`, etc., isolated and testable.
- **No global side effects**: everything scoped within `setup()` and `draw()` of p5.
