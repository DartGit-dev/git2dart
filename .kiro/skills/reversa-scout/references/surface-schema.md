## Campos opcionais

For everyone else, only include what is found.

## Field `organization_suggestion`

Suggestion on how to organize the specs for this project. Read by the Reversa orchestrator to pre-select the default option in the spec organization menu.

### Subcampos

| Field | Type | Mandatory | Description |
|-------|------|-------------|-----------|
| `granularity` | string | yes | One of: `module`, `use-case`, `endpoint`, `hybrid`, `feature`, `custom`. Scout never suggests `custom`, this value only comes from the user's choice. |
| `rationale` | string | yes | Short sentence explaining why this granularity was chosen. Appears in the menu as Scout's "Reason:". |
| `signals` | array | yes | List of detected signals that led to the suggestion. Each item has `type` and `evidence` (path list). May be empty when fallback `feature` is used. |
| `features` | array | yes when `granularity = "feature"` | List of feature names discovered by Scout. Each name becomes a first-level folder. |

### Heuristics for setting `granularity`

| Sinal detectado | `granularity` sugerida |
|-----------------|------------------------|
| Roteamento centralizado (`routes.*`, `urls.py`, `*Controller.cs`, `@RestController`) | `endpoint` |
| Top-level folders with domain names (`auth/`, `orders/`, `payments/`) | `module` |
| Specs Gherkin / E2E orientadas a comportamento (`features/*.feature`, `*.spec.*` BDD) | `use-case` |
| Multiple signals coexisting with similar weight | `hybrid` |
| No clear sign of organization | `feature` (fallback, fill `features` with what was possible to extract) |

### Imutabilidade

After the first run, the orchestrator persists the suggested `granularity` in `.reversa/config.toml` into the `scout_suggestion` field. On re-runs, Scout may regenerate `surface.json` (the legacy may have changed), but the orchestrator does NOT update `scout_suggestion` into `config.toml` (RF-14 of the spec organization spec).

## Nota

Use this schema as a guide. If a field does not apply to the project, omit it except the required fields listed above.
