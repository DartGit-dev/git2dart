Defect and confirmed root cause

fetch runs inside an arena scope but allocates its refspec wrapper, pointer array, and fetch options with global calloc. Neither success nor error unwind releases those call-scoped structures.

Evidence: 3/3 reproduction, root-cause trace, and automated bisect. Bisect identified 02c6784aaf6157c434e62dd99c4248f80d84ee80 as the first bad commit.

Selected strategy — authorized

Direct correction authorized on 2026-08-21. Allocate all three temporary structures from the already active arena, matching the adjacent push implementation. The already-applied O3B3 lexical owner remains unchanged around the fetch operation.
